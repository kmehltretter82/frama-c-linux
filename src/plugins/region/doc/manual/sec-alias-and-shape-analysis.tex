The region map analysis is based on the creation of simple region and then
merges each simple region with relevant ones to build more complex regions.

\subsection{Compound merge}


\begin{lstlisting}
struct S {
    int a, b, c[4];
};
void job (int k) {
    struct S s;
    s.a = 1;
    s.c[k] = 1;
}\end{lstlisting}
