\chapter{\Region plug-in -- Users}
\label{cha-region-plugin}

The \Region plug-in is invoked from the \FramaC{} command line.
It is a dynamically loaded plug-in, distributed with the kernel since the
\textsf{Gallium} release of \FramaC{}.

This plug-in computes an overapproximation of a map dispatching memory
locations into regions.
