\chapter{\Region plug-in -- User Guide}
\label{cha-region-plugin}

The \Region plug-in is invoked from the \FramaC{} command line.
It is a dynamically loaded plug-in, distributed with the kernel since the
\textsf{Gallium} release of \FramaC{}.



The \Region plugin generates a \emph{region map}: an overapproximation of a
map dispatching memory locations into regions using alias and shape analysis.
A region map is defined as a graph (acyclic when no pointer is
involved) whose paths start with program variables represented as labels.
